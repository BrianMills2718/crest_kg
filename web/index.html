01

Entities came from five documents

02

Edges faced stricter review

Endpoints and the predicate must appear faithfully in one exact quote. Invalid candidates remain visible in the rejection ledger.

03

Three edges survived

All three were source-replayed and adjudicated as supported, but the same output helped shape the guard. This is descriptive evidence, not a generalization test.

04

Absence is not evidence

An isolated entity may still participate in real relationships. It only means this checkpoint did not accept an edge for it.
