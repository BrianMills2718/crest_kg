About CREST

From a source search to an evidence graph

This is an active research workbench. Search and inspect real tracked CIA Reading Room records, select documents, and run the repository's traced extraction pipeline.

The bundled archive is currently available. Live CIA search is shown separately and will remain unavailable until its redirect behavior is repaired. The five-document graph is a labeled example checkpoint, not a claim of corpus coverage.
